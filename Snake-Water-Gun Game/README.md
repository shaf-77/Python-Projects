# Snake Water Gun Game 🐍💧🔫

A simple Snake Water Gun game made using Python.

## How to Play

- `s` → Snake
- `w` → Water 
- `g` → Gun 

### Rules

- Snake beats Water
- Water beats Gun
- Gun beats Snake
- Same choice = Draw

## Files

- `main.py` - Complete game using if-elif conditions
- `main-shortened.py` - Shortened version using a simpler logic

## Concepts Used

- Python
- random module
- Dictionaries
- User input
- If-else conditions
